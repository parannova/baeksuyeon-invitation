# 백수연 초대장

서버나 패키지 설치 없이 사용하는 HTML/CSS/JavaScript 초대장입니다.

## 파일 구성

```text
상수연초대장/
├── home/
│   ├── index.html   # 초대 문구, 행사 일시, 달력, 장소와 버튼
│   ├── styles.css   # 색상, 글꼴, 모바일 화면 및 인쇄 스타일
│   └── script.js    # 주소 복사, 공유, 일정 파일 생성, 남은 날짜
├── README.md        # 실행 및 수정 방법
└── sample/
    └── sample.png   # 디자인 참고 원본
```

## 실행

`home/index.html`을 브라우저로 열면 됩니다. Google Fonts의 Noto Serif KR 명조체를 사용하며, 인터넷 연결이 없거나 글꼴을 불러오지 못하면 기기의 기본 명조체로 표시합니다. JavaScript 라이브러리는 사용하지 않습니다.

지도 버튼은 인터넷 연결이 필요합니다. 주소 복사는 브라우저 보안 정책에 따라 복사 입력창으로 대체됩니다. 링크 공유는 웹에 배포한 뒤 사용할 수 있습니다.

## 수정

- 문구·날짜·달력·장소: `home/index.html`
- 배경·글자 크기·간격: `home/styles.css`
- 복사할 주소·저장할 일정·남은 날짜 계산: `home/script.js`

행사 정보는 HTML과 JavaScript 양쪽에 있으므로 변경 시 함께 수정합니다. 시작 시각은 낮 12시이며, 일정 저장의 종료 시각은 임시로 오후 2시 30분으로 설정했습니다.

## GitHub Pages 공개

1. GitHub 저장소에 이 파일들을 올립니다.
2. 저장소 Settings → Pages에서 Deploy from a branch를 선택합니다.
3. 업로드한 브랜치와 `/ (root)`를 선택하고 저장합니다.
4. 배포 완료 후 표시되는 주소 뒤에 `/home/`을 붙여 초대장에 접속합니다.

참석 접수와 방명록 등 데이터를 저장하는 기능은 포함하지 않습니다.
